# 使い方・データ形式

## 入力と時刻

JSON字幕は `[{"start_ms": 0, "end_ms": 2000, "text": "字幕"}]`。キーはこの3つです。
SRTは番号・`HH:MM:SS,mmm --> HH:MM:SS,mmm`・本文の標準形式を使用します。
CLIの時刻は秒（小数3桁まで）または `HH:MM:SS.mmm`。区間は `[start, end)` です。
境界をまたぐ字幕は時刻だけ切り詰めます。出力プランは区間先頭を0とする整数ミリ秒です。
`--duration` は宣言値で、提案作成時に動画を読むわけではありません。レンダリング時には実動画長も検査します。

## 単語装飾とズーム

字幕を選択してピンク／水色にできます。本文を変更すると、ずれた範囲を使わないよう単語装飾を解除します。

```json
{
  "emphasis": false,
  "color": "white",
  "se": "none",
  "zoom": "punch_in",
  "zoom_target": {"x": 0.85, "y": 0.25},
  "spans": [{"start": 3, "end": 7, "color": "pink", "emphasis": true}]
}
```

これは「この子かわいいね」の「かわいい」を指定します。範囲はUnicodeコードポイント単位です。
UTF-16単位／UTF-8バイト位置ではありません。昇順・非重複・本文内・最大32範囲を要求します。
結合文字やZWJ列の途中の分割は拒否しますが、完全な書字素解析や右から左の組版は未対応です。

色: white / yellow / red / cyan / pink。SE: none / pop / surprise / laugh。
ズーム: none / punch_in（1.18倍）/ slow_in（1.0→1.12倍）。
中心座標は0〜1、省略時0.5。端では映像外へ出ないようクロップを制限します。noneなら座標は効果を持ちません。
「かわいい」「残念」は文字列一致規則で最初の出現を装飾します。意味理解や同義語判定はしません。

## レンダリング

FFmpeg/ffprobeとPillow、以下のNotoフォントが必要です。

- `/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc`
- `/usr/share/fonts/opentype/noto/NotoSansCJK-Bold.ttc`

0.5ではWindows/Linux/macOSのNotoフォント候補を検出します（Windows実行は未検証）。明示的な通常・太字フォントパス指定にも対応します。GUIでは360p/720p/1080pを選択できます。プラン生成CLIは標準Pythonで動作します。
字幕は下部帯へ最大3行、1行20文字を目安に配置します。文字幅の計測で安全幅を超えた場合は拒否します。
SEは0.32秒の合成トーンで、商用効果音素材ではありません。元の最初の音声トラックへ加算します。

出力フォルダにはMP4、元のプラン、文字ファイル、SE、フィルター、実行引数、検査結果を保存します。
既存フォルダは拒否します。途中失敗時は診断用ファイルが残るため、新しい名前で再試行してください。
生成物の実行引数にはローカル入力パスが含まれる場合があるので、そのまま公開しないでください。

## IDと互換性

ソース字幕のハッシュ＋区間からclip ID、各字幕からcue IDを作ります。レビューで本文や効果を変えてもcue IDは保持します。
ハッシュは署名ではなく、字幕のIDは実動画の同一性を保証しません。対応する映像か確認してください。
`reconcile` は管理対象の差分プレビューで、編集ソフトを操作・削除しません。
0.4系は旧プランを読み込めます。spans/zoom_target/pinkを含む新プランは旧バリデーターでは拒否されます。

## 検証範囲

Pythonの検証・CLI・実FFmpeg描画と、Nodeの状態遷移／DOM-doubleテストがあります。
DOM-doubleは実ブラウザ試験ではありません。任意の `tests/browser_smoke.py` は別途Playwright/Chromiumが必要です。
CI設定を置いたことだけでは、GitHub上の実行成功を意味しません。
