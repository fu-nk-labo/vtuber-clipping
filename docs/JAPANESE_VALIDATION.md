# 日本語音声の検証（0.5.1）

2026-10-12。32.5秒のオリジナル日本語台本を、ローカルのpyopenjtalk 0.4.1とMei HTS音声で合成しました。実配信・実在人物の声の複製ではありません。台本は「宝箱を探す→古い靴下が出る→中に猫がいる→猫こそ宝物」という短い話です。

## 自動文字起こしの比較

同じ音声、言語ja、CPU int8、最大4スレッド、ONNXを読み込まない通常Whisper経路で比較しました。外部の推論APIは使用していません。

- tiny: 原文143文字に対して40編集、CER 27.97%。「宝箱→高ればこ」「宝物→方もつ」など意味に関わる誤りがあり、日本語デモとして不適切でした
- small: 原文143文字に対して2編集、CER 1.40%。実行約7.0秒。この素材では話の内容と6つの重要語を認識できました

CERはUnicode NFKC・casefold後、空白とUnicode句読点を除外して文字単位編集距離を計算した値です。数字と漢字／仮名の表記差は残しています。小さい合成サンプル1件の結果であり、日本語実配信の認識率を示すベンチマークではありません。

smallで残った本文の差:

| 原文 | 実際の認識 |
|---|---|
| 一時間 | 1時間 |
| 大当たり | 大あたり |

句読点や区切りの空白には別の違いがあります。これらをこっそり原文へ戻した字幕ではありません。字幕の表示整形と、本文の訂正を区別しています。

使用モデルは公式[Systran/faster-whisper-small](https://huggingface.co/Systran/faster-whisper-small)、MIT。取得リビジョン536b0662742c02347bc0e980a01041f333bce120。4ファイル合計486,212,372bytes。model.binのSHA256は3e305921506d8872816023e4c273e75d2419fb89b24da97b4fe7bce14170d671。重みはソース配布に含みません。

## 切り抜き候補と確認事項

小型Qwen3-0.6Bによる最初の日本語候補は0.44〜31.74秒で、宝箱から猫までの話を含んでいました。ただし、説明に音声・映像を見聞きしたかのような根拠のない文言がありました。引用と時刻が正しくても説明の意味的な正しさは保証できません。

ASRの最後の時刻31.74秒より後にも実際の発声が残っていました。最終デモでは検証時の明示的なレビュー操作として、クリップ末尾を元動画の32.5秒まで延長しました。これはユーザーが承認した操作や、自動候補の品質合格として記録しません。元の候補と変更後のプランを別々に保存します。

この検証で追加した対策:

- 文末記号、800ms以上の実際の無音間隔、真の字幕全体の端を候補境界として使用。文脈ウィンドウの端を文末とはみなさない
- 区切りが見つからない場合は警告し、無理に文途中の候補を作らない。無音間隔も意味上の文末を保証しない
- 短すぎる連続したASR字幕の末尾断片は、本文を変更せず実測の最初／最後の時刻を保って前の字幕へまとめる
- 日本語の自動改行では小書き仮名や閉じ句読点を行頭に置かない
- 「かわいい」と「可愛い」の表記を、文字列一致ルールで単語だけピンクにする

意味の通る候補、自然な音声の切れ目、正しい理由説明を全自動で保証する状態ではありません。対象Windows/GPU、ゲーム音や重なった声を含む実配信、固有名詞の品質は未検証です。
